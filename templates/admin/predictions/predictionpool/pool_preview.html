What this does

Posts one match's messages into the pool's channel so you can look at them: the prediction poll, the pre-kickoff reminder, the live score and the full-time result. They are built by the same code a real match night runs, so what you see is what the channel gets.

Nothing is scored and nothing is tracked — votes on a test poll are ignored, the match still gets its real poll later, and no mention fires, so previewing the reminder pings nobody. Use Remove below to delete a set of test messages again.

Buttons & modals is the exception to "nothing is real": it posts every clickable component the bot uses, and they are the live ones — clicking the notification button opens the actual modal and saves your actual setting. A modal only opens in response to an interaction, so that message is the only way to see one at all.

The admin cannot talk to Discord, so this leaves the bot an order and the bot posts it within about 15 seconds. If nothing appears, the bot is not running.
